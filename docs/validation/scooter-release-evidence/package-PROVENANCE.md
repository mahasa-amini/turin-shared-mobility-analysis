# Scooter release provenance and scope

Publication authorization: the owner explicitly instructed public publication of the real scooter inputs as GitHub Release assets on 15 October 2026. This follows the previously recorded owner publication authorization. It authorizes this publication; it does not assign an open-data license or promise unrestricted reuse. No conflicting scooter redistribution restriction was found in the available staging/provenance records. No dataset license is assigned. Original provider/course agreements, acquisition dates and broader reuse grants are not supplied and are not invented.

Source: the existing local distribution staging package dated 14 October 2026, owner-scooter part only. The 40 payload hashes and byte sizes match that package's manifest and the inputs used in the recorded raw-to-harmonized reproduction. Payload bytes, filenames and relative data/raw paths are unchanged. This release adds scooter-specific README, provenance, a filtered 40-file manifest and per-input SHA-256 checksums; the separate release checksum file identifies the entire archive. The original private staging package, including its unpublished external-review and runtime-config parts, is preserved.

Files: two annual Bird CSVs (2024 and 2025 through 18 November), 16 monthly Lime CSVs (2024 and January–April 2025), 22 monthly Voi workbooks (2024 and January–October 2025). Raw row total: 2,774,313. Unequal coverage and original export defects remain present. This is the original raw input snapshot, not a cleaned or harmonized data product.

Retained fields: Bird/Lime ID_VEICOLO and Voi Targa veicolo identify vehicles; Voi Identificativo noleggio identifies rentals. All source start/end timestamps and endpoint latitudes/longitudes remain. DISTANZA_KM/DURATA_MIN or KM Tot/Tempo Tot, reservation indicators, and Lime/Voi battery readings remain. Vehicle/rental IDs and precise trip times/endpoints can support linkage with other observations. No direct rider-name, rider-email, rider-phone or credential columns were found across all actual export schemas. A full-cell heuristic scan checked email, credential and explicitly labelled telephone patterns without emitting values, and reported no matches. This is not a guarantee of anonymity or exhaustive detection of unlabelled personal text.

Bird PERCORSO entries are all empty or N/A; Lime/Voi contain no route trace column. Voi damaged January timestamp codes remain damaged, not intentionally anonymized. Operator-specific cleaning decisions and common-schema semantics are documented in docs/data-quality.md in the source repository. The inspection report is docs/validation/scooter-release-evidence/column-inspection.json; it lists columns, sheet names, counts and input hashes, not trip values.

Excluded: all Torino statistical-zone and GTT GTFS files, runtime configuration (already tracked in Git), cleaned/interim/harmonized files, suspicious/removed/duplicate exports, reports, credentials and local caches. External snapshot-specific redistribution evidence remains unresolved, so this release grants no rights or access to those files. Source code/configuration and dependencies come from the repository; no license is inferred across mixed assets.
